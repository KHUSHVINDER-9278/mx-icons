# 🚀 MX Icons

A modern and customizable icon library designed for developers to easily integrate scalable and reusable icons into web applications.

---

## 📌 Overview

MX Icons is a lightweight and developer-friendly icon system that provides a collection of clean, scalable, and customizable icons. It is built to simplify UI development and improve design consistency across projects.

---

## ✨ Features

* 🎨 Clean and modern icon design
* ⚡ Fast and lightweight
* 🔧 Easy to integrate into any project
* 📦 Scalable vector-based icons
* 🌐 Suitable for modern web applications

## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash

cd YOUR_REPO
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run the project

```bash

```
